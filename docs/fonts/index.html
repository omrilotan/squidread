Add fonts to Squidread

Squidread reads fonts from a folder on your device: the one you chose in the Aa menu, usually called fonts. Any .ttf or .otf file you put there shows up in the font picker.

For example, Noto Serif

Noto Serif is a free, clear book font from Google Fonts.

  1. Open Noto Serif on Google Fonts and tap Get font, then Download all.
  2. Open the downloaded file in your file manager and extract it.
  3. In the extracted static folder, copy these four files to your fonts folder:
    • NotoSerif-Regular.ttf
    • NotoSerif-Bold.ttf
    • NotoSerif-Italic.ttf
    • NotoSerif-BoldItalic.ttf
  4. In Squidread, open Aa and pick Noto Serif.

The other files in the download are condensed and lighter versions you don't need. If your books use another alphabet, Google Fonts has a Noto font for it too: search for "Noto Serif" and add the same four styles.

Any other font

Name the files after the font, then the style, like Literata-Regular.ttf and Literata-Bold.ttf, and Squidread groups them into one font with its bold and italic.
